# Graph Builder (배포용 저장소)

설치 없이 브라우저에서 쓰는 탐색형 그래프 도구 **그래프 빌더**의 **빌드 결과(정적 파일)만** 담은 저장소입니다. 소스 코드는 포함하지 않습니다. 이 저장소의 내용은 자동으로 만들어지므로 직접 수정하지 마세요.

## 사용하기

**https://forrestgump3210-wq.github.io/graphbuilder_yk/**

주소를 열기만 하면 바로 쓸 수 있고, 데이터는 서버로 전송되지 않고 내 브라우저 안에서만 처리됩니다. 사용법은 [사용 설명서](https://forrestgump3210-wq.github.io/graphbuilder_yk/guide/)를 보세요.

## 안내

- **무단 재배포 금지**: 이 저장소의 파일과 앱을 허락 없이 재배포하거나 복제해 게시하지 마세요.
- 별도의 라이선스를 부여하지 않았습니다.
